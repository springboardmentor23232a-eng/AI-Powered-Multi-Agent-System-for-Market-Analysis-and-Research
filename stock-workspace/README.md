# Multi-Agent Stock Research Analyst — Module 1
User Authentication and Research Workspace (React + Tailwind · FastAPI · SQLAlchemy · PostgreSQL · JWT · bcrypt)

## Features (mapped to the guide)
| Guide section | Implementation |
|---|---|
| 1. Registration | `AuthPage.jsx` + `POST /api/auth/register` (validation, duplicate-email check, bcrypt hash) |
| 2. Login | `POST /api/auth/login`, clear error for bad credentials |
| 3. JWT | Token has only user id + expiry, stored in an **HTTP-only cookie**; CSRF header + SameSite=Lax; expired/invalid → 401 → sign-in screen |
| 4. Research history | `research_tasks` table, status Pending → Processing → Completed/Failed, live polling, open report modal; user id always taken from the JWT |
| 5. Watchlist | Search by name/ticker, add, remove, research from saved stock, unique (user, ticker) |
| 6. Preferences | Market (NSE/BSE/NASDAQ/NYSE) and period (1M–5Y) saved per user and used by research |
| 7. Database | `users`, `saved_stocks`, `research_tasks` with PK/FK/unique/index (`backend/schema.sql`) |

Dynamic UI: login/register tabs with live validation and password-strength meter, dark mode, toasts, debounced search,
status filters, auto-refreshing task list, interactive SVG price chart, responsive layout.

## Run it
### 1. Backend
```bash
cd backend
python -m venv .venv && source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt
# Optional PostgreSQL: createdb stock_research, then export DATABASE_URL from .env.example
# (without DATABASE_URL a local SQLite file is used so it works instantly)
uvicorn app.main:app --reload --port 8000
```
API docs: http://localhost:8000/docs · Tests: `pytest`

### 2. Frontend
```bash
cd frontend
npm install
npm run dev        # http://localhost:5173  (proxies /api to port 8000)
```

## Notes
- Research reports are **demo data** generated by `backend/app/reports.py`; later modules replace `build_report` with the real agents and a market-data API (`stocks.py` holds a validated ticker list and `provider_symbol()` for `.NS` / `.BO` formats).
- Production: set `JWT_SECRET`, `COOKIE_SECURE=true`, serve over HTTPS, add login rate limiting.
